# 🛒 Grocery Shopping App

I developed a modern and user-friendly **Grocery Shopping Mobile Application** that provides a complete shopping experience, from onboarding and authentication to product browsing, favorites, cart management, and category-based shopping.

## 🚀 Key Features

### 👋 Onboarding

The application starts with professionally designed **onboarding screens** that introduce users to the application and its main features.

### 🔐 Authentication

The app includes professional **Sign Up and Login screens** that provide users with an easy and organized authentication experience.

### 🏠 Home Screen

The home screen displays a variety of grocery products along with their details.

Users can:

* View product information
* Add products to the cart
* Add products to favorites
* Explore available products

### ❤️ Favorites

Users can mark products as their favorites.

The **Favorites screen** displays all products selected by the user, making it easy to access preferred products.

### 🛒 Shopping Cart

Users can add products to their cart and manage their purchases.

The cart allows users to:

* View selected products
* Increase product quantity
* Decrease product quantity
* View the total price of selected products

### 📂 Categories

The application includes a dedicated **Categories screen** where products are organized into different categories.

Users can:

* Browse different categories
* View products within each category
* View product details
* Add products to favorites
* Add products to the cart

### 💾 Persistent Data Storage

I used **SharedPreferences** to persist important user selections such as favorites and cart data.

This means the selected data remains available even after the user:

* Closes the application
* Exits the application
* Opens the application again

### 🧭 Bottom Navigation

The application includes a professional bottom navigation bar with four main sections:

* 🏠 Home
* 👤 Profile
* ❤️ Favorites
* 🛒 Cart

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **SharedPreferences**
* State Management
* Responsive UI Design

## 🎯 Project Objective

The main objective of this project was to develop a complete **Grocery Shopping Mobile Application** with a smooth and user-friendly shopping experience.

The project demonstrates practical implementation of **authentication UI, product management, category-based browsing, favorites, shopping cart functionality, quantity management, total price calculation, persistent local storage, and modern mobile UI design**.
